# OpenDMSBackend

`OpenDMSBackend` is the backend of [OpenDMS](../ReadMe.md), an ASP.NET Core web-API.

## Development

See the [hints](./Other/Reference/ReferenceContent/Hints.md) for the requirements, how to run the backend locally (including the transient in-memory persistence used for local debugging) and how document-indexing (tags and custom metadata-fields) works.

## Build and test

This codeunit is built and tested as part of the repository's [common-project-structure](../ReadMe.md#repository-structure) pipeline (`scbuildcodeunits`), not with a standalone command.
