# Release notes

## Changes

- the findings of the code-reviews and of the OWASP-Top-10-analysis are collected in one table in the section "Findings" of the product reference (`Other/Reference/Reference.md`), with their state determined from the source-code (44 open, OWASP-34 and Backend-02 partially fixed, none fixed). The finding-lists in the readme and in the hints of the backend- and the frontend-codeunit were replaced by a reference to that table, and the specification documentation-accuracy allows fixed findings to stay in that table with a struck-through id
- the new specification findings defines that every finding of a code-review, a security-analysis, a bug-search, a performance-analysis or another analysis is collected in the findings-table in the section "Findings" of `Other/Reference/Reference.md`, which columns that table has, that the state of a finding is determined from the source-code, and that a fixed finding stays in the table with a struck-through id
- the colors of the frontend were reworked into a single source of truth with one palette per theme-mode (`src/styles/_theme-colors.scss`), applied everywhere through Angular-Material's Material-3 theme: light-mode now has a very light, cool-white background with deep navy text and accents, and dark-mode a dark, GitHub-like grey background with light, non-white grey text; to restyle the application the palettes are changed there instead of overwriting single color-tokens
