# Licenses of the delivered fonts

The fonts which this web-application delivers are not covered by the `License.txt` of this product, because they
are third-party-content with their own license. Their license-texts are located in this folder and are delivered
together with the fonts, which their licenses require.

| Font | File | License |
| ---- | ---- | ------- |
| Roboto | [Roboto.txt](./Roboto.txt) | SIL Open Font License 1.1 |
| Material Icons | [MaterialIcons.txt](./MaterialIcons.txt) | SIL Open Font License 1.1 |

The fonts are included as the npm-packages `@fontsource/roboto` and `@fontsource/material-icons`, so they are
also listed in the bill of materials of this codeunit. The files in this folder are the license-texts of exactly
these packages.
